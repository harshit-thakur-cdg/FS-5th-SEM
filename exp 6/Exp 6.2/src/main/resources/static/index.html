Optimization Concepts

N+1 Problem: Additional database queries can occur when related entities are loaded separately.
JOIN FETCH: Loads related entities together using a single optimized query.
Caching: Stores previously retrieved results for faster repeated access.
Native SQL: Executes SQL directly against the database tables.
