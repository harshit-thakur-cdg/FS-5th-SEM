Experiment 9.2 Runbook

GUIDE
01   Healthy Canary Rollout (10% → 50% → 100%)

Start candidate v1.1.0 with 10% traffic. Click Send 100 Lab Requests. Health gates confirm 0 failures. Advance rollout to 50%, verify a second batch, then promote to 100%. The candidate seamlessly becomes the new stable baseline.

02   Anomaly Detection & Automated Safety Rollback

Start candidate v1.2.0. Click Inject Candidate Anomaly to simulate microservice failure. Send 100 requests. The health gate detects errors and triggers instant automated rollback, restoring 100% traffic to stable without operator intervention.

03   Production Docker & Nginx Deployment

For production deployment, run docker compose up --build -d. The root compose config launches separate backend and frontend containers with upstream routing via deploy/release.sh.

04   Submission Artifact Checklist

Capture screenshots at 10% canary, 50% load split, 100% promotion, the automated rollback alert, and export the signed JSON evidence containing your student attribution.
